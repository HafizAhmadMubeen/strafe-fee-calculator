STRAFE Fee Calculator
=====================

Fills the STRAFE Testing Calculator from the endorsement test workbook and writes
the calculated Fee Amount back into the sheet.


FOR USERS
---------
Open the  App\  folder.
  - Run "STRAFE Fee Calculator.exe"
  - Follow "User Guide.pdf" in that folder.
You need Microsoft Edge (already installed on every work PC). Nothing else.


FOR THE MAINTAINER
------------------
  Source\   - the Python source, build script, and full README / planning notes
  docs\     - User Guide and Build & Deploy Guide (Markdown)
  Sample workbook\ - an example test workbook

To rebuild the .exe:  open Source\ , run  build_exe.bat  (needs the .venv set up
once - see docs\Build and Deploy Guide.md).
